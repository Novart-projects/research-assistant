## Проблема

При чтении научной статьи часто приходится постоянно переключаться между самой статьёй и её источниками. Чтобы разобраться в каком-либо утверждении, нужно открывать десятки ссылок, искать нужный абзац и восстанавливать контекст вручную.

Существующие чат-интерфейсы над статьями обычно ограничиваются содержимым одного документа и не учитывают сеть цитирований, на которой строится научная работа.

## Идея решения

Система позволяет загрузить научную статью (PDF, arXiv-ссылка и т.д.) и построить интерактивное пространство знаний вокруг неё.

После загрузки документа:

- Из статьи извлекается текст и список цитируемых источников.
- Для каждой статьи создаётся отдельное индексируемое пространство знаний.
- Векторный индекс содержит как исходную статью, так и связанные с ней публикации.
- Пользователь может задавать вопросы на естественном языке и получать ответы с указанием конкретных источников и фрагментов текста.

Вместо поиска по одному документу система фактически предоставляет поиск по локальному графу научных публикаций.

## План работы

1. Провести разведочный анализ данных: изучить тексты научных статей и цитируемые источники.
2. Реализовать базовый поиск релевантных фрагментов с помощью BM25.
3. Добавить семантический поиск с помощью биэнкодера, используя векторные представления запросов и фрагментов текста.
4. Добавить кросс-энкодер для переранжирования найденных фрагментов по релевантности запросу.
